# rainmaker-proposal

Elishah Partner Network deck: operating model, economics, IP and governance for Elishah, our product partner (Dimuthu) and commercial partners (rainmakers), aimed at European businesses in any sector.

- `deck/index.html` is the presentable deck, a single self-contained HTML file. Open it in a browser. Use ← / → or click to move between slides and `F` for fullscreen. `#N` in the URL jumps to slide N.
- `deck/elishah-partner-network.pdf` is the PDF export (29 slides, 16:9).
- `scripts/build-pdf.sh` regenerates the PDF from the HTML using headless Chrome.

Fonts load from Google Fonts. Offline, the deck falls back to system fonts.
